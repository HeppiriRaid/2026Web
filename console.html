Sign in

The console saves straight to the website on GitHub. Paste your GitHub access token for it here. It stays in this browser and is only ever sent to GitHub.

How to make a token
  1. On GitHub, open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it Website console and pick an expiry (a year is fine).
  3. Repository access: Only select repositories → HeppiriRaid/2026Web.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  5. Generate it, copy it, and paste it above. Don't paste it anywhere else.
